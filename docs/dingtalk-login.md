# 钉钉个人授权

入口：设置 → 手机交互。

## 使用

1. 打开「手机交互」。未安装 DWS 时，点击「一键安装组件」，岛仔将从官方来源下载 Windows 安装器，在后台安装组件到本机 `tools/dws` 目录，并跳过 AI 技能包。官方安装器可能将目录加入当前用户 PATH，无需另装 Node.js。下载或安装失败可重试，也可查看 [官方安装说明](https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli#installation)。已安装的设备不重复安装，支持检测 PATH、官方默认目录及官方 npm 包中的原生程序。
   安装完成后自动验证组件并检查登录状态，再点击「登录钉钉」授权。期间可以取消安装；取消不会卸载已完成的文件，重新安装会再次检测现有组件。只有点击安装按钮才会执行安装，打开岛仔不会静默下载安装。
2. 点击「登录钉钉」。官方组件会打开浏览器，通过本机回环地址完成 OAuth 授权。无需填写钉钉密码、AppSecret 或令牌；请在官方页面核对授权内容。
3. 已登录 DWS 的用户可以点「刷新状态」复用登录。界面显示组织、用户名与登录状态。多个账号时可自行选择；没有明确默认账号时不会选择列表第一项。
4. 「取消等待」结束岛仔启动的登录进程；如浏览器页仍打开，可自行关闭。取消并不撤销已经完成的钉钉授权。
5. 「取消绑定」仅移除岛仔记住的账号，不执行 DWS 全局退出，也不影响其他程序使用的登录。彻底撤销授权需在钉钉或官方组件中操作。

## 凭据与范围

- 令牌由官方 DWS 组件管理，岛仔不会导出、复制或上传 access token、refresh token，也不把原始登录输出写入日志。
- 岛仔只在本机 `dingtalk-link.json` 保存所选的组织/用户标识。它不参与 WebDAV 同步。其他设备分别登录。
- 登录不自动申请 CLI 的全部推荐业务权限，不代表机器人配置、通知发送和引用消息读取权限均可用；各项能力按实际操作结果判断。
- 登录本身不启用业务操作。机器人通知与回复继续任务需在「手机交互」中选择应用机器人并单独开启，详见 [机器人交互说明](dingtalk-bot.md)。旧待办交互已停用；回复作为普通用户消息排队到 Codex 原任务，不能代替操作审批。
- 适配 PATH 中的 DWS 原生程序及官方 npm 包的原生程序；仅有自定义包装脚本时可能需要调整官方组件安装。

## 验证

合成数据检查账号选择、同组织不同账号隔离、令牌有效性和返回内容解析。浅色、深色界面预览不使用真实账号。手动本机登录检查只读取官方组件的账号/认证状态（官方组件可能自动续期），不创建业务对象。
